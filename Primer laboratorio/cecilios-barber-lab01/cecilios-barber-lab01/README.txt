Cecilio's Barber - Landing Page Responsiva

Estructura del proyecto:
- index.html
- css/styles.css
- js/app.js
- img/
- video/trabajo-bg.mp4

Notas:
- El CSS está separado en la carpeta css.
- El JavaScript está separado en la carpeta js.
- Las imágenes están separadas en la carpeta img.
- El video de fondo está separado en la carpeta video.
- El carrito usa localStorage y solo abre WhatsApp al confirmar el pedido desde el panel del carrito.
- El botón Agregar solo guarda cortes o productos dentro del carrito.
- El modo claro/oscuro se controla desde Ajustes con un checkbox: marcado = modo claro, sin marcar = modo oscuro.
- WhatsApp configurado: 50686199888.
